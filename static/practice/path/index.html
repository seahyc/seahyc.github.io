        How to use this path

        Start where your hands are

        Guided example → faded scaffold → small functions from memory. Run syntax checks early. Once the basics work, mix a coding task with a short explanation. On a difficult day, one 20-minute repair still counts.

        Transfer, then rehearse

        Use fresh mocks for tasks you haven’t opened in this browser. The browser cannot know what you have seen elsewhere. Repeated mocks count as practice, not fresh transfer. All test suites and prompts are public; this is a learning tool.

        When the bank is exhausted, ask a peer or coach to write a new task with different constraints. Do not reset history to make an old problem look new.

        Practice the whole job

        Applied systems emphasizes discovery, implementation, evaluation, demos and customer tradeoffs. Engineering depth emphasizes concurrency, scheduling, inference systems and model fundamentals. Both include project ownership, judgment, clear communication and unfamiliar code.

        Use assistance deliberately

        Coaching and worked examples belong in learning sessions. In a mock, follow its declared rules. For an actual assessment, confirm the allowed tools, time limit, language, environment and accommodations directly with the organizer. Documentation access and AI assistance are separate permissions.

        Keep your stories true

        Draft from your own experience. Use a coach to sharpen your explanation, never to invent achievements or rehearse beliefs you do not hold.

        What this path does and does not measure

        Coding tasks execute in real browser Python. Rehearsal feedback is recorded by you; no interviewer listens automatically and no AI evaluates your answers here. Copy a coach prompt to use with a separate coach, or rehearse with another person. No audio is recorded or uploaded.

        Model fundamentals is a starting clinic, not a complete research curriculum. A specialized role can require deeper math, training, kernels, distributed systems or domain study. Use the rehearsal gaps and the actual role description to choose that next work.

        Code and path progress stay in this browser. Backups include your private notes and stories; keep them private. Export before switching browsers or clearing storage. A target date helps allocate practice; it never relaxes the evidence thresholds.

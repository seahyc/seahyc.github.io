# First-party sources checked

Checked 2026-09-06. Feature descriptions are supplier claims, not independently benchmarked performance guarantees.

| Source | Evidence used |
|---|---|
| [Browserbase](https://www.browserbase.com/) | Reports 35M+ monthly sessions and 10,000 customers; usage does not establish revenue or paid-customer count. |
| [Browserbase enterprise](https://www.browserbase.com/enterprise) | Persistent sessions, files, live view, replay, and identity. |
| [Browserbase agent identity](https://www.browserbase.com/blog/identity) | April 6, 2026 announcement of identity work involving Web Bot Auth, Cloudflare, Fingerprint and 1Password; site participation still matters. |
| [Steel documentation](https://docs.steel.dev/) | Persistent profiles, browser hosting, anti-bot handling and observability are bundled. |
| [Bright Data Browser API](https://brightdata.com/products/scraping-browser) | Browser interactions and multi-step flows are explicitly advertised, alongside integrated access handling. |
| [Context.dev](https://www.context.dev/) | Structured extraction, brand/company data, screenshots, crawling and markdown. |
| [Apify](https://apify.com/) | Hosted automation and scraper marketplace; also a potential distribution channel. |
| [DataForSEO pricing](https://dataforseo.com/pricing/serp/google-organic-serp-api) | Base Google organic price: $0.60 per 1,000 queued first-page SERPs, $2 live; additional options and depth can increase cost. |
| [Skyvern](https://www.skyvern.com/blog/how-to-automate-government-form-submissions-with-browser-automation/) | Advertises checkpoints, saved progress and approval pauses for multi-page workflows. |
| [TinySeed acquisition announcement](https://tinyseed.com/latest/scrapingbee-s2020-acquired-oxylabs-group) | ScrapingBee eight-figure all-cash acquisition by Oxylabs' group. |
| [Founder interview](https://www.startupsfortherestofus.com/episodes/episode-783-bootstrapping-scrapingbee-to-5m-arr-and-an-8-figure-exit) | $5M ARR reported at exit; historical, not a claim about current ARR. |
| [Apify / Web Scraping Club survey](https://get.apify.com/hubfs/apify-state-of-web-scraping-report-2026.pdf) | December 2025 community sample; 58.3% reported higher proxy spending. Self-selected practitioner survey, not representative TAM. |
| [Coresignal jobs API](https://coresignal.com/solutions/jobs-data-api/) | Existing normalized, deduplicated and historical jobs data competition. |
| [TheirStack API](https://theirstack.com/en/docs/api-reference) | Existing jobs, company and technology data competition. |

The acquisition announcement page and founder interview have different publication contexts; no exact transaction-closing date is inferred. No market-report TAM or unverified social throughput claim is used to estimate obtainable revenue.
